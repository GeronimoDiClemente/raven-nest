# H6 — Google Calendar — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development o superpowers:executing-plans. Steps con checkbox `- [ ]`.

**Goal:** Registrar outcomes reales de las sesiones en el calendario (Motor 4 inversa) y abrir un bloque como sesión con un click, con OAuth desktop (loopback + PKCE, sin client secret).

**Architecture:** Adapter `gcal.ts` credential-free (token vía deps); OAuth PKCE + loopback server en main; refresh del access token en main; handler de bus `logOutcome` (ya tipado) escribe en la description del evento; receta `pr.merged → logOutcome`; UI mínima "Start session" reusa `initialInput` (H4).

**Tech Stack:** Electron main (http loopback, crypto PKCE), TS, React, vitest. Google Calendar API v3 + OAuth2.

**Spec:** `docs/superpowers/specs/2026-07-30-h6-calendar-design.md`. Depende de H4 (`initialInput`) y H8 (`logOutcome` en `bus-types.ts`).

**Sin credenciales Google en el entorno → NO se testea en vivo; toda la cobertura es unit tests con `fetch`/servidor mockeados.**

```ts
import { createHash, randomBytes } from 'crypto'

function base64url(buf: Buffer): string {
  return buf.toString('base64').replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
}

/** PKCE S256. `verifier` opcional para tests determinísticos; si no, se genera. */
export function pkceChallenge(verifier?: string): { verifier: string; challenge: string } {
  const v = verifier ?? base64url(randomBytes(32))
  const challenge = base64url(createHash('sha256').update(v).digest())
  return { verifier: v, challenge }
}

export interface OutcomeInput { repo: string; branch: string; prNumber?: number; commits?: number; testsGreen?: boolean }
export function formatOutcome(o: OutcomeInput): string {
  const parts = [`${o.repo} (${o.branch})`]
  if (o.commits != null) parts.push(`${o.commits} commits`)
  if (o.prNumber != null) parts.push(`PR #${o.prNumber}`)
  if (o.testsGreen != null) parts.push(o.testsGreen ? 'tests verdes' : 'tests rojos')
  return `🪺 Nest: ${parts.join(', ')}`
}
```

(El challenge esperado del test es el vector de ejemplo del RFC 7636.)

async function handleLogOutcome(cmd: LogOutcomeCommand, deps: PanelAdapterDeps, opts: BusCommandDeps): Promise<void> {
  const gcal = opts.gcal?.(deps)
  if (!gcal) { console.warn('[bus-commands] logOutcome sin gcal, no-op'); return }
  try {
    const ev = await gcal.findEventByTask(cmd.ref)
    if (ev) await gcal.appendOutcome(ev.id, cmd.summary)

  } catch (err) { console.warn('[bus-commands] logOutcome falló', err) }
}

  const clientId = import.meta.env.MAIN_VITE_GCAL_CLIENT_ID ?? ''
